نظام المنافذ والجوازات الذكي (نسخة العمل المحلي)

يبدو أنك فتحت ملف المصدر الخام مباشرة من محرر الأكواد عبر بروتوكول الملفات دون تجميع Vite. للعمل محلياً بدون إنترنت بشكل فوري، افتح النسخة المجمعة الجاهزة في مجلد dist:

تشغيل النسخة المحلية الجاهزة (dist/index.html)
أو من موجه الأوامر (Terminal):
1. لتشغيل وضع التطوير: npm run dev
2. لبناء نسخة الويب المحلية: npm run build ثم تشغيل مجلد dist
